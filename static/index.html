03 / WHAT BIOAUDIT DOES

A map between
words and work.

Bioaudit looks for checkable parameter names, numeric values, and a selected vocabulary of method calls across the paper and repository. It scans Python, R, C/C++, and selected script formats without running the repository.

01Read the claim

Extract named methods and stated parameters from selectable paper text.

02Scan the source

Find corresponding constants, options, imports, and method calls in supported code.

03Follow the evidence

Review file paths, line numbers, code snippets, and the analyzer's rationale.
