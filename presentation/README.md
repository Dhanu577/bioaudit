# Bio-Audit Presentation Assets

This folder collects presentation-ready materials alongside the web application and Python static-analysis backend.

## Contents

- `video/` — the 94-second narrated Bio-Audit explainer, standalone captions, and a source-assets bundle
- `architecture/` — the system architecture image and editable Mermaid/HTML source
- `slides/` — the playful output-slide image and editable HTML source
- `nine-verdict-demos/` — nine small manuscript/code pairs, each prepared to illustrate one Bio-Audit verdict, plus the convenient ZIP bundle

The video demonstrates the validated C++ `PACK_SIZE = 1000` match and explains that performance claims need execution or benchmarking. The application remains a static-analysis aid; it does not run repository code or establish scientific validity.
